# WARLORD

![Concept](https://img.shields.io/badge/Concept-F-red) ![Effort to Cashflow](https://img.shields.io/badge/Effort_to_Cashflow-92%2F100-red)

Sandbox Multiplayer FPS — a Unity + Photon PUN prototype with basic lobby/room matchmaking, player controller, and two placeholder guns (last touched 2020).

## 💰 Path to Revenue
Multiplayer FPS is one of the most brutally competitive genres; this tutorial-level prototype would need a near-total rebuild with a distinctive hook before any revenue is plausible.

### Release TODOs

- [ ] Upgrade to a current Unity LTS and a modern netcode stack (Photon Fusion or Unity NGO)
- [ ] Replace prototype assets: real maps, weapon models, animations, sound
- [ ] Build core progression/retention systems (loadouts, unlocks, matches that persist stats)
- [ ] Stand up dedicated or relay-hosted servers and playtest with 8+ concurrent players
